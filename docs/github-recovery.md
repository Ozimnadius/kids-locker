# Восстановление с GitHub

Начиная с v0.5.0 независимый загрузчик `Recovery\GitHubRecovery.ps1` и задача SYSTEM `KidsLocker-GitHubRecovery` могут восстановить программу даже при отсутствии обоих exe. Задача использует системный Windows PowerShell 5.1 и запускается при обычной загрузке и раз в минуту. Работающая резервная служба также запускает загрузчик при отсутствии копии.

Порядок: проверенная локальная копия предпочтительна. Если основной exe отсутствует и резервная копия не проходит проверку, скачивается файл из публичного репозитория `Ozimnadius/kids-locker`. Используется точная установленная версия из `Recovery\github.json`, а не latest. Токены, учётные записи и автоматическое обновление не требуются.

Доверенный SHA-256 берётся из `Recovery\enabled.sha256`, сохранённого при установке. Хеш из сети не используется как основание доверия. Скачанный файл проверяется до запуска, а запущенный ремонт повторно проверяет собственный хеш и манифест под блокировкой установки. Если во время загрузки произошло штатное удаление или обновление, ремонт отменяется. Существующий основной exe другого хеша не заменяется.

Ремонт возвращает отсутствующий основной файл, запускает/восстанавливает основную службу, исправляет резервную копию, резервную службу и задачи. Исправный открытый основной файл не перезаписывается. Манифест и основная служба не удаляются при ремонте, поэтому временная ошибка не отключает повторное восстановление. Пароль, Telegram, расписание и режим тест/бой сохраняются.

HTTPS-соединение имеет обычную проверку сертификатов. Разрешены только github.com и домены выдачи release-assets.githubusercontent.com / objects.githubusercontent.com; редиректы на HTTP или посторонний сервер отклоняются. Общий сетевой таймаут — 60 секунд, размер — до 120 МиБ. Отдельная блокировка исключает параллельные загрузки, при этом сеть не удерживает блокировку установки. Временные файлы удаляются после попытки; ошибки записываются в ограниченный по размеру `Recovery\github.log`.

## Границы

- Нужны интернет и доступность именно установленного релиза GitHub. Изменённый после установки файл релиза будет отклонён из-за другого SHA-256.
- Безопасный режим без сети допускает только локальное восстановление. Если оба exe удалены до загрузки безопасного режима, запуск отдельной задачи загрузчика не гарантируется; остаётся обычная загрузка с сетью или ручная установка.
- Если удалены также скрипт, манифест, сведения о версии или задача, независимая загрузка не гарантируется. Администратор может удалить все механизмы.
- Это восстановление программы, а не защита от администратора, меняющего локальный доверенный хеш.
- Изолированные тесты и анонимное скачивание проверены; реальная автоматическая установка служб и SYSTEM-задача на целевом ПК здесь не запускались.

Чтобы включить возможность, запустите новую версию и нажмите «Установить (боевой)». Предварительно удалять старую не нужно. Штатная кнопка удаления отключает и локальное, и сетевое восстановление.
