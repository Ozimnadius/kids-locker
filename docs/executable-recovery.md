# Восстановление программы

Начиная с v0.3.0 установщик сохраняет проверенную резервную копию:
`%ProgramData%\KidsLocker\Recovery\KidsLocker.Recovery.exe`.

Основной файл службы — `%ProgramFiles%\KidsLocker\KidsLocker.exe`. Скачанный файл из «Загрузок» для дальнейшей работы не требуется.

Отдельная задача `KidsLocker-Recovery` запускает резервную копию с `--recover` от SYSTEM при обычной загрузке Windows и каждую минуту. Если основного exe нет, она проверяет SHA-256 копии, возвращает файл атомарно и запускает службу. Отсутствующая служба пересоздаётся с основным путём и ранее сохранённым режимом (тест/бой). Расписание, пароль и Telegram не перезаписываются.

Если файл существует, восстановитель его не заменяет: старой копией нельзя откатить обновление. При установке новой версии создаётся новая копия. Работающая служба раз в пять минут проверяет наличие резервной копии и задачи; вернуть копию можно только из основного файла с ожидаемой контрольной суммой.

## Обновление и удаление

Для обновления запустите скачанную новую версию и нажмите «Установить (боевой)». Удалять предыдущую версию не требуется.

Кнопка удаления в разделе «Служба» сначала отключает восстановление и удаляет задачи, затем удаляет службу и данные. Общая блокировка предотвращает одновременные установку, удаление и восстановление. Без манифеста `Recovery\enabled.sha256` оставшийся восстановитель ничего не делает.

Папки данных и восстановления получают полный ACL с владельцем «Администраторы»: SYSTEM и администраторы могут изменять файлы, обычные пользователи — только читать и выполнять. Ссылки/точки подключения вместо этих папок не принимаются. Новые exe и манифест наследуют защищённые права.

## Ограничения

- Задаче нужен работающий планировщик. В безопасном режиме её выполнение не гарантируется; при обычной загрузке она снова доступна.
- При удалении обеих копий восстанавливать нечего. Пользователь с правами администратора может отключить все механизмы; абсолютной защиты от него нет.
- SHA-256 выявляет повреждение; это не цифровая подпись против администратора, заменившего одновременно копию и хеш.
- Интернет не нужен. Скачивание с GitHub в эту версию не входит.
- Проверка выполняется примерно раз в минуту, с учётом доступности планировщика и времени запуска. Мгновенное восстановление не обещается.

Диагностика `--diagnose` показывает наличие копии, включённость восстановления и её путь. В журнале сохраняются успешное восстановление и ошибки.
