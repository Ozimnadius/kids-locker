# Загрузочный слой — ручная настройка

Это самая важная часть. Пока сын — администратор Windows, программную защиту он в теории
может отключить. Настоящую стену ставят BIOS и BitLocker: они не дают загрузиться в обход
Windows и удалить/сбросить что-либо offline. Делается один раз, руками.

## 1. Пароль BIOS — правильно

В BIOS обычно два независимых пароля:

- **Power-On / User password** — спрашивается при каждом включении. Именно он заставлял
  вводить пароль каждое утро. **Убери его.**
- **Supervisor / Setup / Admin password** — нужен только для входа в настройки BIOS.
  **Поставь его** (и не сообщай сыну).

Итог: компьютер включается сам, утром ничего вводить не надо, но изменить порядок
загрузки, Secure Boot или пароли сын не сможет.

## 2. Запретить загрузку с USB/CD

В BIOS:
- отключи Boot from USB / CD, либо убери их из Boot Order;
- по возможности включи **Secure Boot**;
- сохрани. Теперь live-USB (Linux, установщик Windows с Shift+F10) не загрузится — а это
  главный способ сбросить пароли или удалить файлы службы в обход Windows.

## 3. BitLocker — шифрование системного диска

Зачем: без шифрования диск можно вынуть или загрузиться с флешки и удалить/подменить файлы
(например, подменить `utilman.exe`/`sethc.exe` и получить SYSTEM-консоль на экране входа).
BitLocker это закрывает.

1. Панель управления → **Шифрование диска BitLocker** → включить для диска C:.
2. Сохрани **ключ восстановления** в свой аккаунт Microsoft или распечатай. Сыну — нет.
3. Если есть TPM (обычно есть) — включение прозрачное, при обычной загрузке пароль не
   спрашивается.

Бонус: если сын сбросит настройки BIOS (перемычкой/батарейкой на десктопе) или поменяет
Secure Boot, BitLocker при следующем включении **потребует ключ восстановления** — то есть
без тебя система не загрузится, и ты сразу это заметишь.

## 4. Про сброс BIOS батарейкой

- На **десктопе** пароль BIOS можно сбросить, вынув батарейку/перемычкой — доступ к
  «внутренностям» это позволяет. Защита здесь — BitLocker (см. выше): после сброса система
  запросит ключ, который есть только у тебя.
- На **ноутбуке** это сложнее (разбор корпуса, часто пароль в отдельной микросхеме).

## 5. Честные пределы

- Сын с правами администратора и физическим доступом при большом желании и знаниях может
  что-то придумать. Цель слоёв — сделать это **трудным и заметным**: любой обход внутри
  Windows прилетит тебе в Telegram, а BIOS+BitLocker отрезают простые пути в обход системы.
- Абсолютная защита достигается только снятием прав администратора у сына. Если однажды
  передумаешь — это самый надёжный шаг, и KidsLocker с ним становится практически
  неснимаемым.
