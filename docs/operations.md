# KidsLocker — как пользоваться

Всё делается в приложении кнопками. Никакой командной строки.

## 1. Получить приложение

Файл `KidsLocker.exe` — один самодостаточный файл (на ПК сына .NET ставить не надо).
Разработчику для сборки: `powershell -ExecutionPolicy Bypass -File install\Publish.ps1`
→ появится `publish\KidsLocker.exe`.

## 2. Создать Telegram-бота

1. В Telegram напиши **@BotFather** → `/newbot` → задай имя. Он выдаст **токен**
   (строка вида `123456789:ABCdef...`). Сохрани.
2. Напиши своему новому боту любое сообщение (например, `привет`) — обязательно, иначе
   бот не сможет определить твой chat_id и писать тебе.

## 3. Запустить и настроить (на ПК сына, из своей учётки)

1. Скопируй `KidsLocker.exe` на ПК сына и запусти двойным кликом. Появится запрос
   **Windows (UAC)** — разреши (нужны права администратора).
2. **Мастер-пароль.** При первом запуске задай пароль — его будешь вводить только ты.
   Сын не должен его знать: без него в приложение не войти.
3. Раздел **Telegram** (меню слева):
   - вставь **токен**;
   - нажми **«Определить автоматически»** — chat_id подставится сам (ты ведь уже написал
     боту в шаге 2). Или впиши число вручную, если знаешь;
   - **«Проверить связь»** — тебе придёт тестовое сообщение от бота;
   - **«Сохранить»**.
4. Раздел **Расписание**: задай разрешённое время по дням (например `07:00-23:00`,
   `24:00` = полночь). Переключатель «Контроль включён». **«Сохранить расписание»**.
   Если в поле опечатка, пульт подсветит её красным, объяснит, что не так, и не сохранит.
   Пустое поле — день запрещён целиком.
5. Раздел **Служба**:
   - сначала **«Установить (тест)»** — ничего не выключает, для проверки;
   - убедись, что статус «Служба работает», а в Telegram приходят события;
   - потом **«Установить (боевой)»** — включает реальное выключение по расписанию.

## 4. Загрузочный слой (обязательно, руками)

Приложение — не абсолют, пока сын администратор. Реальную стену ставят BIOS и BitLocker:
сними пароль BIOS на включение, поставь пароль только на настройки BIOS, запрети загрузку
с USB, включи Secure Boot и BitLocker. Подробно — [hardening.md](hardening.md).

## 5. Ежедневное управление — с телефона в Telegram

| Команда | Действие |
|---|---|
| `/status` | что сейчас |
| `/schedule` | расписание |
| `/allow будни 07:00-23:00` | задать время (дни: пн вт ср чт пт сб вс, будни, выходные, все) |
| `/extra 60` | +60 минут сегодня |
| `/pause 2h` | пауза контроля |
| `/resume` | снять паузу |
| `/off` / `/on` | выключить / включить контроль |
| `/shutdown` | выключить компьютер сейчас |

Те же действия есть кнопками в разделе «Расписание».

## 6. Что придёт в Telegram сама (алерты)

- вход в запрещённое время (комп выключается);
- службу останавливали / удаляли (восстановилась);
- меняли системное время или часовой пояс;
- правили файл расписания вручную (откатилось).

## 7. Удалить

Запусти `KidsLocker.exe`, введи мастер-пароль, раздел **Служба** → **«Удалить»**.

## 8. Где что лежит

- приложение/служба: `C:\Program Files\KidsLocker\KidsLocker.exe`
- настройки, расписание, пароль: `C:\ProgramData\KidsLocker\`
- журнал: Просмотр событий → Журналы Windows → Приложение → источник `KidsLocker`
