# Восстановление с публичного GitHub

Репозиторий Ozimnadius/kids-locker проверен: PUBLIC. Пользователь поручил добавить GitHub к уже выпущенному локальному восстановлению. Выбор исполнителя: восстанавливать точную установленную версию, не выполнять автообновление.

Установщик сохраняет версию релиза рядом с enabled.sha256 и независимый встроенный PowerShell-загрузчик. Новая задача SYSTEM запускает powershell.exe при обычной загрузке и раз в минуту; основной и резервный exe ей не нужны. Работающая резервная служба также может запустить этот загрузчик при неудаче локального восстановления.

Загрузчик предпочитает проверенную локальную копию. Если основной exe отсутствует и нет проверенной резервной копии, скачивает KidsLocker.exe по фиксированному HTTPS URL версии из единственного репозитория. SHA-256 сверяется с хешем, сохранённым при установке; хеш из сети не используется как основание доверия. Размер ограничен 120 МиБ, общий сетевой таймаут 60 секунд; перенаправления только HTTPS на github.com и домены выдачи GitHub.

Сеть выполняется вне mutex установки, отдельный mutex предотвращает дубли. После скачивания повторно проверяются манифест и версия. Проверенный временный exe запускается с --repair-from-github; он под mutex ещё раз сверяет собственный хеш с текущим манифестом и только затем возвращает отсутствующий основной файл, проверяет запуск основной службы, исправляет резервную копию/службу и задачи. Исправный основной exe не перезаписывается; манифест и основная служба не удаляются даже при ошибке, поэтому ремонт можно повторить. Сохранённый режим не меняется. Это закрывает гонку с обновлением/удалением. Временный файл удаляется. Токены GitHub не используются.

Если удалены все копии вместе со скриптом, манифестом или задачей, восстановление не гарантируется. В безопасном режиме без сети скачивание невозможно. При удалении обоих exe до загрузки безопасного режима запуск независимой задачи не гарантируется; остаются обычная загрузка с сетью или ручная установка. Настройки, пять минут ожидания и UTC+3 неизменны.

План: тесты C# на закрепление версии и проверку разрешения ремонта; реальные тесты скрипта под Windows PowerShell 5.1 в изолированных папках с подставной загрузкой/запуском; реализация и интеграция установки/удаления; проверка настоящего анонимного скачивания опубликованного файла; независимая проверка; CI; релиз v0.5.0 и проверка его скачивания.
