# План восстановления установленного exe

Цель: возвращать отсутствующий установленный exe из отдельной копии и запускать службу, сохраняя настройки и режим.
Архитектура: файловое хранилище копии с SHA-256, отдельная задача SYSTEM, общий mutex жизненного цикла.
Стек: C#, .NET 10, Task Scheduler, Windows ACL.
Спецификация: ../specs/2026-11-15-executable-recovery-design.md

Решения: новая возможность получает v0.3.0; все операции с установленной службой проверяются через изолированные файловые тесты и подставные действия. Запуск реального восстановителя на рабочей машине запрещён в проверках: он мог бы создать службу. SHA-256 проверяется перед публикацией восстановленного файла; повреждённая копия не запускает службу.

Проверено локально: 153 теста, включая файловое восстановление, обновление, отказ повреждённой копии, сохранение режима и конкуренцию с удалением. Собранный автономный exe восстановлен в изолированной папке, SHA-256 совпал; восстановленный exe успешно выполнил --diagnose. Системные службы, задачи, реестр и права ProgramData/Program Files на этой машине не менялись. Проверка ACL ограничена сформированной политикой; фактическое применение проверяется при установке (ошибка останавливает установку). Проверка кода выявила и закрыла неполный ACL ранее созданной папки и влияние ошибки копии на остальные защиты.
